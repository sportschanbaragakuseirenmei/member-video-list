プライバシーポリシー

このページは、スポーツチャンバラ YouTube チャンネルのメンバー限定動画を検索するためのページ「メンバー動画検索」（以下「本サービス」）と、その一覧を更新するための仕組み（アプリ名「再生回数更新」）での情報の扱いを説明するものです。運営：日本スポーツチャンバラ学生連盟。

取得する情報

本サービスの閲覧者から、氏名・メールアドレスなどの個人情報は取得しません。ログインも不要です。Cookie や解析ツールも使っていません。

一覧の更新のため、チャンネル運営者自身の Google アカウントで、YouTube Data API の読み取り専用の許可（youtube.readonly）を使い、チャンネルに投稿した動画の再生回数だけを取得します。動画の追加・変更・削除は行いません。

試合動画の投稿・整理のため、チャンネル運営者自身の Google アカウントで、YouTube Data API の許可（youtube.upload・youtube）を使い、運営者が撮影・編集した試合動画のアップロード、タイトルや再生リストの設定、公開設定の変更を行います。対象はチャンネル運営者自身のチャンネルの動画だけで、他のユーザーの情報を取得・保存することはありません。

利用目的

取得した再生回数は、本サービスの一覧で「再生回数順」に並べ替え、表示するためだけに使います。動画の投稿・整理の許可は、運営者自身のチャンネルの動画を管理するためだけに使います。

第三者への提供

取得した情報を第三者に販売・提供することはありません。本サービスは GitHub Pages で公開しており、一覧のデータ（動画ID・タイトル・公開日・再生回数など、YouTube 上ですでに公開されている情報）はリポジトリ内に保存されています。

Google API サービスの利用

本サービスによる Google API から受け取った情報の利用と他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシー に従います。許可は Google アカウントの設定 からいつでも取り消せます。
